# PYTHON-Text-Based-Tic-Tac-Toe-Game
***DESCRIPTION***

This project was put together as a laboratory assignment during my time in CSCI 220L (Programming I Lab) at the College of Charleston.
The assignment was to program a text-based tic-tac-toe game that would allow for interaction from two players, having to include all of the following:
custom functions; conditional statements; while loops; print statements; a list to represent the board; input variables

Upon running the program, the board will be printed out and prompt the players to select <enter> to begin the game. On player 1's turn, they should enter a number that is available on the board. When they have selected their number and hit "enter", the board will be reprinted with an "x" character in the spot they selected. It will then swap to player 2's turn, where they should do the same thing, and the spot they select will fill in with an "o". This will continue until either the user(s) exit, or the game is won, upon which the program will stop itself.

I'm making this project available to the public in case anyone is working on something similar and would like to use this as a reference, but also to receive feedback; in its current form this project does not account for any user-entered errors (i.e. if player 2 selects a spot that player 1 already took, or if one of the players enters a number that is not on the board, and so on) and if anyone has any ideas on how to fix this, I'm all ears!

***HOW TO USE***

One should have IDLE or some other Python IDE installed. The file containing all of the code for this project is attached within this repository. Make sure you have a copy of the code saved (downloaded the file given or copy-pasted into your own Python file). When you have the code ready, run it with your IDE.
